FROM SEARCH TO INFERENCE

How to add a quantized model

  1. Choose a supported checkpoint. Start with or . The repository must contain standard safetensors and declare the supported format in its configuration.
  2. Update and connect your nodes. Both the controller and nodes need this Soul version. Older nodes cannot serve quantized checkpoints. For gated models, accept the publisher’s license and set HF_TOKEN on the controller and each node.
  3. Select “Check compatibility”. Soul reads configuration and tensor headers without downloading the model weights. Review the format, weight memory estimates, context limit and compatible node count.
  4. Select “Prepare model”. Choose “Preload to disk” or “Preload and load GPU”. Soul pins the checked revision and downloads only each node’s assigned tensors. Soul downloads the shards that fit now. An ! warning marks incomplete models in the control room; missing pieces are distributed automatically when compatible nodes join. Choose “Distribute missing” after freeing capacity. “Available” means ready for inference from cache.
  5. Use the exact repository ID in API requests. Open “Use model” in the control room for connection instructions. No separate adapter upload or quantization flag is needed.
Formats, memory and performance

AWQ requires 4-bit AutoAWQ GEMM packing with zero points. GPTQ requires the 4-bit v1 layout, including group indices; activation ordering is supported. GEMV, Marlin, GPTQ v2, mixed-bit settings and quantized output heads are not supported.

Packed weights stay compressed in memory. Small blocks are expanded during computation using PyTorch. This saves weight memory and works with resident or streamed layers, but may be slower than unquantized models or specialized GPU engines. Embeddings, the output head, activations and KV cache remain floating point. Memory estimates are lower bounds; preparation checks actual node budgets.

The portable adapter uses the existing CPU, CUDA and Metal runtime. Numerical tests cover CPU, with Metal and CUDA checks when those devices are available. Device-specific performance and capacity depend on your hardware.
