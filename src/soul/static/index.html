Connect another machine

Run the Bash commands on the machine you want to contribute. It will connect to this controller and serve assigned model layers.

Install and connect in one command

For Apple Silicon macOS or Linux x86_64/ARM64. The installer selects CPU, Metal, or a compatible NVIDIA profile; no Git checkout or existing Python installation is needed.

curl -fsSL https://mastrogiovanni.ddns.net/soul/install.sh | bash

Keep the terminal open to contribute. Press Ctrl+C to stop. To connect again:

~/.local/share/soul/bin/soul-node
