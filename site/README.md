# Soul community

One model. Many machines. Soul brings shared compute to communities and nonprofit organizations for language-model work that can run in the background.

**[Visit the website](https://mastrogiovanni.github.io/soul-community/)** · **[English website](https://mastrogiovanni.github.io/soul-community/en/)** · **[Open the admin panel](https://mastrogiovanni.ddns.net/soul/)**

**[Star the Soul application repository on GitHub](https://github.com/mastrogiovanni/soul)** to support the project. The application repository is currently private and requires access.

## Connect a machine

Run this in a terminal on Apple Silicon macOS or Linux x86_64/ARM64:

```bash
curl -fsSL https://mastrogiovanni.ddns.net/soul/install.sh | bash
```

Keep the terminal open to contribute; press `Ctrl+C` to stop. Find requirements and installation options on the [community website](https://mastrogiovanni.github.io/soul-community/#join).

## Admin and API access

The [admin panel](https://mastrogiovanni.ddns.net/soul/) requires the controller’s admin token. Open **Overview → Connect a node** or **Nodes → Connect a node** for Bash connection instructions. Open **Models → Use model** for inference client examples. Inference uses a separate API key supplied by the operator; see the [API reference](https://mastrogiovanni.ddns.net/soul/docs).

## About this repository

This public repository hosts the community website. Application development lives in [mastrogiovanni/soul](https://github.com/mastrogiovanni/soul), which currently requires repository access. Website files are published from that application repository; contribute website changes there if you have access, or contact the [community operator](https://github.com/mastrogiovanni).
